## 2024-05-18 - Memoized Coaches Directory Filtering
**Learning:** In a single-page React app (like Gridiron Gateway) lacking a server-side backend, large mock datasets processed directly inside component rendering bodies are vulnerable to performance drops. Specifically, filtering the \`coaches\` array in \`CoachesDirectory.tsx\` based on multiple parameters (\`searchQuery\`, \`selectedConference\`, \`selectedPosition\`) on every render can cause noticeable lag. Unrelated state changes, such as typing in a message modal, will trigger this expensive operation continuously if not memoized.
**Action:** Always wrap heavy list filtering inside a \`useMemo\` hook, especially when the list can grow substantially or when the component manages other state variables that trigger frequent re-renders (like user input forms or modals).
